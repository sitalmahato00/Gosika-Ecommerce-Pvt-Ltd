# GOSIKA Seller Portal – Phase 1 Manual Generation

## Directory Structure

```
GOSIKA-Manuals/
└── Seller/
    ├── screenshots/              ← All PNG screenshots (auto-generated)
    ├── source/
    │   ├── capture_seller_manual.js    ← Playwright automation script
    │   ├── generate_pdf.py             ← ReportLab PDF generator
    │   ├── workflow-inventory.md       ← Workflow tracking document
    │   ├── screenshot-manifest.json   ← Auto-generated by capture script
    │   └── README.md                   ← This file
    └── GOSIKA-Seller-User-Manual-Phase-1.pdf  ← Final output
```

## Prerequisites

### 1. Node.js & Playwright
```powershell
# From the Gosika Ecommerce project root:
npm install --save-dev @playwright/test
npx playwright install chromium
```

### 2. Python & PDF Libraries
```powershell
pip install reportlab pillow
```

### 3. Application Running
Make sure the GOSIKA application is running:
```powershell
cd "D:\Gosika Pvt. Ltd\Gosika Ecommerce"
php artisan serve
```

## Step 1: Capture Screenshots

```powershell
cd "D:\Gosika Pvt. Ltd\Gosika Ecommerce\GOSIKA-Manuals\Seller\source"
node capture_seller_manual.js
```

**What happens:**
1. A Chrome browser window opens to the Seller Login page.
2. **You must manually log in** with your seller account credentials.
3. After logging in, press **ENTER** in the terminal to continue.
4. The script automatically navigates through all Seller Portal pages.
5. Screenshots are saved to `../screenshots/`.
6. A `screenshot-manifest.json` is created with the screenshot index.

**Safety notes:**
- The script only reads pages (read-only navigation).
- It does NOT create products, accept orders, or change any data.
- It pauses before any potentially consequential action.

## Step 2: Generate the PDF

```powershell
cd "D:\Gosika Pvt. Ltd\Gosika Ecommerce\GOSIKA-Manuals\Seller\source"
python generate_pdf.py
```

**Output:** `GOSIKA-Seller-User-Manual-Phase-1.pdf`


## Troubleshooting

| Problem | Solution |
|---------|----------|
| Browser doesn't open | Ensure Chromium is installed: `npx playwright install chromium` |
| Page not loading | Check the app is running: `php artisan serve` |
| Screenshot blank | The page may need longer load time – increase `LOAD_WAIT` in the script |
| PDF generation fails | Check `pip install reportlab pillow` completed successfully |
| Screenshot not found in PDF | Check the filename in the manifest matches the file in screenshots/ |
